Design-language §5 · Slice T · the type draw (§6.1)

Setting the type on real words.

The families below are the shortlist the design language named — all real, all OFL, all self-hosted. This lap sets them on the Department's actual content, at both light levels, so the choice is made on the work and not on a foundry poster. The real fork is the display: European-elegant Didone (the engraved plate) against American-mechanical slab (the streamliner). Body leans toward Newsreader, mono toward IBM Plex Mono — shown here so you can confirm or overrule. Nothing on this page is chosen.

The draw

This is the operator's call alone (design-language §6.1). The specimen is built; the choice is not made. Picking resolves three values, each set in one place — the type-role tokens in assets/shell.css — after which every current and future page inherits the family with no rebuild:

  • --font-display — the fork: Direction A (Cardo / Cormorant, Didone) or Direction B (Zilla Slab). This is the aesthetic decision.
  • --font-body — Newsreader (shown as the leader), or Source Serif 4 / Literata.
  • --font-mono — IBM Plex Mono (leader), or JetBrains Mono / Courier Prime.

The Glitter Test still governs: the type serves the store, it doesn't decorate it. When the draw lands, the deferred fallbacks in shell.css (currently Georgia / ui-monospace) are replaced by the chosen families as the first token in each stack — one edit, three lines.
